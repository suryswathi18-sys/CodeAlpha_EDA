# CodeAlpha_EDA

Exploratory Data Analysis on a retail sales dataset, completed as part of the CodeAlpha Data Analytics Internship.

**Dataset:** Retail Sales Dataset (1000 transactions, 9 columns) — includes customer demographics, product category, quantity, and total spending.

**Key Findings:**
- Electronics generates the highest revenue despite similar average price and quantity per transaction compared to other categories
- Customers aged 46-55 are the top-spending demographic
- Dataset was clean with no missing values

**Tools used:** Python, Pandas, Jupyter Notebook
